# ⚔️ 심연 원정대

잿더미가 된 왕국의 마지막 용병단. 친구들과 길드를 만들어 밤마다 심연으로 내려가는 **온라인 실시간 협동 로그라이크 RPG**.

- **온라인 2~3인 (3인 권장)** — 방장이 방을 열고 코드 4자리로 접속. 서버 없음 (PeerJS P2P + 정적 호스팅)
- 계정은 **닉네임 + 비밀코드 6자리**, 길드 데이터는 접속한 모든 멤버 기기에 복제 (누가 방장을 해도 이어짐)
- 설치 없이 `index.html` 을 열거나 배포 주소로 접속

## 조작
| 동작 | 키 |

⛓️ 성기사 · 💀 강령술사 · 🔫 총잡이 · 🌿 드루이드 (길드 성장으로 해금)

## 한 판의 흐름
길드 홀(술집에서 심연 단계·저주 선택) → 노드 맵 투표 → 전투 / 정예 / 이벤트 / 상점 / 모닥불 / 보물 / 시련 → 지역 보스 → 귀환 투표 → 결과(MVP · 재미상 · 전멸 원인 제공자)

- 어그로·도발, 속성 반응(폭발·분쇄·독연·감전·증기), 다운 → 부활 → 유령 응원
- 강화 카드 3택1, 유물 60종, 장비 니드/그리드 롤, 영구 성장은 +30% 캡
- 심연 단계 1~10, 저주 12종, 주간 도전, 보스 러시, 무한 심연

## 개발
- 순수 HTML + JS + Canvas, 빌드 없음. 모든 수치는 `src/config.js`, 콘텐츠는 `src/data/`
- headless 테스트: `node test/harness.js [런 수] [시드]` — 봇 3명이 자동으로 런을 돌고 오류·NaN 을 보고
- 혼자 테스트: `index.html?bots=2` 로 방을 열면 봇 2명이 파티에 들어온다
